# 🚗 부.읽.카

### 출퇴근길, 내 경로의 부동산 소식을 듣다

**부동산 읽어주는 자동차**는 출퇴근 경로의 부동산 소식을 요일별로 읽어 주는 **Pleos Connect 차량용 라디오 앱**입니다.

내비게이션으로 들을 지역을 정하고, 공공 데이터로 소식을 모아 한국어 음성으로 전합니다.

> 손과 눈은 운전에, 귀는 내 지역의 소식에.

현재 Pleos Connect 에뮬레이터에서 개발 중인 프로토타입이며, 실차 검증은 아직 진행하지 않았습니다.

## 📻 주요 기능

| 기능 | 설명 |
| --- | --- |
| 요일별 편성표 | 월~금마다 최대 두 주제를 1부·2부로 편성 |
| 드래그 편집 | 카드를 끌어 추가·이동·교환·삭제 |
| 경로별 방송 | 출발지·경유지·목적지의 시군구별 소식 구성 |
| 새 지역 소식 추가 | 주행 중 새로 확인한 지역의 소식을 방송에 추가 |
| 내비 연동 자동 재생 | 앱 실행 상태에서 내비의 경로 시작 이벤트에 맞춰 재생 |
| 오디오 중단·재개 | 일시적인 포커스 상실 시 멈추고 복귀하면 이어 읽기 |
| 오늘의 핵심 | 방송 마지막에 주요 내용을 짧게 정리 |

### 운전에 맞춘 듣기

- 방송 시작 시 남은 시간에 맞춰 소식 분량을 조절합니다.
- 다른 오디오와 겹친 자동 재생은 최대 30초 기다립니다.
- 플랫폼의 주행 제한에 따라 편성·설정 조작과 대본 표시를 제한합니다.
- 가로·세로 화면과 내비 옆 분할 화면에 대응합니다.

## 🗓️ 소식 카테고리

매일 같은 정보를 반복하기보다, 요일마다 다른 주제를 들을 수 있도록 구성했습니다.

| 카테고리 | 주요 내용 |
| --- | --- |
| 분양·청약 | 접수 일정, 당첨자 발표일, 분양가, 청약 결과 |
| 주택가격지수·증감률 | 주간 아파트 매매가격지수와 변화 |
| 실거래가·신고가 | 거래 건수, 조회 월 최고 거래가, 거래가 많은 단지 |
| 전월세 시세 | 전월세 계약, 보증금, 월세 |
| 교통 호재 | 철도·도로·광역교통 관련 소식 |
| 개발 호재 | 신도시·택지·개발 관련 소식 |
| 재건축·재개발 | 정비사업 관련 소식 |
| 정책·규제 | 주택·부동산 제도 관련 소식 |
| 금리·대출 | 기준금리와 주택담보대출 금리 |
| 미분양·입주물량 | 미분양·입주·주택통계 관련 소식 |

※ ‘실거래가·신고가’는 현재 카테고리명입니다. 과거 전체 거래와 비교하는 역대 신고가 판정은 구현하지 않았습니다.

## 🧭 이용 흐름

1. 앱을 실행하고 위치 정보 이용에 동의합니다.
2. 편성표에서 듣고 싶은 주제를 배치합니다.
3. 내비 경로 또는 저장된 경로를 선택합니다.
4. ‘오늘 방송 듣기’를 누릅니다.
5. 자동 듣기를 켜두면 내비의 경로 시작 이벤트에 맞춰 재생을 시도합니다.

재생 화면에서는 일시정지·재개, 다음 소식, 처음부터 듣기, 방송 종료를 조작할 수 있습니다.

## 🏗️ 동작 구조

```text
내비의 현재 위치·경유지·목적지
                ↓
V-World로 시군구·지역 코드 확인
                ↓
공공 데이터 및 보도자료 조회
                ↓
지역별·주제별 대본 구성
                ↓
Pleos 온디바이스 TTS 재생
                ↓
오늘의 핵심 정리
```

대본은 생성형 AI 없이 **규칙 기반 템플릿**으로 만듭니다. 숫자와 일정은 원본 데이터가 제공하는 범위에서 사용합니다.

## 🗂️ 데이터 출처

| 정보 | 출처 |
| --- | --- |
| 아파트 매매·전월세 | 국토교통부 실거래가 공개 데이터 |
| 청약 공고·분양가·경쟁률 | 청약홈 |
| 주택가격지수 | 한국부동산원 R-ONE |
| 기준금리·주택담보대출 금리 | 한국은행 ECOS |
| 교통·개발·정비사업·정책·주택통계 | 국토교통부 보도자료 |
| 좌표의 시군구·법정동코드 | V-World |

- 청약: 이번 주·다음 주 일정
- 실거래·전월세: 최근 완료 월 중 자료가 있는 월
- 보도자료: 최근 31일 자료

일부 카테고리는 지역 소식이 없으면 시도·전국 소식으로 범위를 넓힙니다. 소식이 없거나 조회에 실패하면 해당 사유를 안내합니다.

## 🔑 API 키 설정

프로젝트 루트의 `local.properties`에 키를 작성합니다. (현재 심사를 위해 개인 프로젝트용 개발계 API Key가 코드에 포함되어 있습니다.)
Android Studio가 생성한 `sdk.dir` 항목은 유지합니다.

```properties
RONE_API_KEY=
VWORLD_API_KEY=
ECOS_API_KEY=
DATA_GO_KR_API_KEY=
```

- `DATA_GO_KR_API_KEY`에는 URL 인코딩된 공공데이터포털 키를 사용합니다.
- API별 이용 신청과 승인 상태를 확인해야 합니다.
- 현재 앱은 API를 직접 호출하므로 APK에 키가 포함됩니다.

발급처와 상세 API는 [API 목록](docs/API_목록.md)을 참고하세요.

## ▶️ 실행 및 빌드

1. Android Studio에서 프로젝트를 엽니다.
2. Gradle 동기화를 진행합니다.
3. API 키를 설정합니다.
4. Pleos Connect 에뮬레이터를 실행 대상으로 선택합니다.
5. 앱을 실행합니다.

명령어로 APK를 빌드할 수도 있습니다.

```bash
./gradlew assembleDebug
```

APK 생성 경로:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 🎬 시연 주행

홈의 **시연 주행**으로 실제 GPS 이동 없이 지역 추가 동작을 확인할 수 있습니다.

- 내비 안내 경로가 있으면 해당 경로를 사용합니다.
- 안내 경로가 없으면 **하남 → 강동 → 송파 → 강남**의 지정 경로를 사용합니다.
- 지점마다 18초 대기 후 지역을 조회합니다.
- API 응답 시간과 데이터 제공 상황에 따라 진행 간격과 방송 내용이 달라집니다.

시연 주행은 실제 내비 위치 갱신이나 실차 주행을 검증하는 기능은 아닙니다.

> 촬영을 위해 현재 `RadioViewModel.kt`의 `BROADCAST_DAY`가 월요일로 고정돼 있습니다. 실제 요일을 사용하려면 `null`로 변경합니다.

## 📌 현재 동작 범위

- 자동 재생은 앱이 실행 중일 때 내비 이벤트를 받는 방식입니다.
- 종료된 앱을 내비가 자동 실행시키는 기능은 없습니다.
- 처음 구성한 지역은 실제 진입을 기다리지 않고 방송 순서대로 읽습니다.
- 방송 중 경유지·목적지를 변경해도 기존 방송을 자동으로 다시 구성하지 않습니다.
- 내비 경로 편집 과정의 종료 이벤트로 방송이 종료될 수 있습니다.
- 경유지 좌표가 없으면 최근 장소의 ID·제공자·하위 ID가 유일하게 일치할 때만 복원합니다.
- 복원할 수 없는 경유지는 제외하며, 복원 조회는 최대 8초 추가 대기합니다.
- 주행 중 추가된 소식까지 남은 시간에 맞춰 분량을 다시 조절하지는 않습니다.
- 영구적인 오디오 포커스 상실 후에는 수동 재생이 필요합니다.
